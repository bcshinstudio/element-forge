# Wellspring trailer prototype
Open index.html on Pages. Press Play to unlock audio. Use Load gameplay files to select the four prepared stage-6.mp4, stage-21.mp4, stage-31.mp4, stage-33.mp4 clips if not hosted. Copy those files into trailer/media/ to publish permanently. Footage is muted to avoid conflicting music; original procedural Wellspring soundtrack is reused. Stage 31 and 33 play at 2x, Stage 21 at 1.5x. The prepared clips must start at the intended source in-point; do not substitute raw footage without checking framing. Space pauses in recording mode, Escape returns controls. No advanced mechanics clips are supplied; no fabricated demonstrations.
