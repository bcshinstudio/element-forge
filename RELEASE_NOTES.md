# Wellspring 1.0.0

- Play 96 campaign stages across eight chapters. Connect elemental sources to inlets and use bridges, tunnels, intersections and portals to make room for each route.
- Explore chapter palettes, illustrated story scenes and animated restorations. Music and sound effects can be adjusted independently.
- Use the visual map editor to decorate campaign stages or build and test custom puzzles.
- Play in a desktop or phone browser. Standalone HTML builds are available for offline use.

The campaign update uses the existing puzzle layouts and rules. Progress and settings are kept by the browser. Use the same browser and hosted site address to continue an existing hosted save.
